# CHIROMBE · House of Masawi

Local office for the house. The page keeps a cycle of 1,200 recitations of the Lord’s Prayer, a falling field of 1,200 ancient symbols, a sounding tone, and a talisman for every named person.

The watch runs while the page is open. It does not reach outside the browser, and it does not replace a lock, a doctor, or the law.

```bash
npm install
npm run dev
```
